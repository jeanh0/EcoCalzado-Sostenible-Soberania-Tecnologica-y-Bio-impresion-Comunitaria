# EcoCalzado-Sostenible-Soberania-Tecnologica-y-Bio-impresion-Comunitaria
Repositorio oficial del sistema de economia circular, bio-impresion 3D y manufactura descentralizada para la produccion de calzado funcional de bajo costo, integrando residuos agricolas de olote de maiz y latex natural mediante un modelo operativo de cuatro estaciones y vinculacion academica.
